# 安全说明

## 支持范围

本项目只支持腾讯 QQ 机器人开放平台及腾讯官方 SDK。不会加入个人 QQ 协议逆向、客户端 Hook、注入、模拟点击或绕过平台限制的实现。

## 默认防护

- 私聊默认使用空白名单，群聊默认关闭；空白名单会拒绝所有消息。
- `open` 模式必须同时设置 `acknowledgeOpenAccess: true`，否则插件拒绝启动。
- 群聊默认必须 `@机器人`。
- Agent 工作目录不能是文件系统根目录或用户主目录。
- 日志默认不记录消息正文，QQ OpenID 只以不可逆短指纹显示。
- 扫码得到的 AppSecret 只写入 `$DSH_HOME/.env`，不会写入插件配置或输出到终端。
- 扫码用户 OpenID 同样只写入 `$DSH_HOME/.env`；仓库配置通过环境变量读取白名单。
- 权限审批仅允许原任务发送者一次性授权，超时和取消均失败关闭。

## 安全边界

DSH Agent 可能拥有读写文件、执行命令或访问网络的能力。QQ 白名单并不能替代 DSH 的沙箱与工具权限。请为 QQ profile 使用专用工作目录、最小权限 preset，并避免把个人主目录、密钥目录或生产环境挂给 Agent。

文件权限只能阻止其他操作系统用户，不能阻止以同一系统账号运行的 Agent 主动读取文件。高价值密钥应使用独立运行账号或操作系统密钥服务隔离。

## 报告漏洞

公开仓库建立后，请通过 GitHub Security Advisory 私下提交漏洞，不要在公开 Issue 中粘贴 AppSecret、OpenID、聊天记录或日志附件。

报告前请运行 `pnpm privacy:check`，并删除二维码 URL、消息 ID、TraceId 和附件签名地址。
